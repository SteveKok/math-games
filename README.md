# 思维小游戏 · Think & Play

给 8–12 岁孩子的免费、开源网页小游戏：先玩、先试错、自己发现规律，通关后再用一句话点破背后的数学。

> 项目重新开始：之前的三个游戏（取石子、说谎者与诚实者、一笔画与涂地图）已移除，代码仍保存在 git 历史里（提交 `b5e7328` 及之前）。

- 纯静态：HTML + CSS + JavaScript，无构建步骤、无后端、无账号
- 不收集任何信息、没有追踪脚本；进度只存在本机浏览器（localStorage，读写都包 try/catch）
- 所有图形用 SVG / Canvas 代码绘制，音效用 WebAudio 现场合成（可静音）
- 三语：华语、英语、马来文（Bahasa Melayu）
- 大字、高对比、触屏友好；失败不惩罚，没有倒计时
- 用户开了「减少动态效果」时不做动画

## 怎么玩

直接双击 `index.html`（脚本用普通 `<script>` 加载，`file://` 下也能运行），或者：

```bash
python3 -m http.server 8765
```

## 游戏 1：鸽子与糖果（抽屉原理）

一步步走向 **2016 年马来西亚全国数学奥林匹克（OMK 2016）Bongsu 组 B 部分第 3 题**：
1000 颗糖分给 n 个小朋友（可以分到 0 颗），最小的 n 是多少，才一定有两人分到一样多？（答案 46）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 鸽子回家 | 1–3 | 点窝放鸽子，每窝有上限：4 进 3（放不下）、8 进 4 每窝 2（刚好放满）、10 进 3 每窝 3（放不下）。放不下就按「做不到！」 |
| 都不一样多 | 4–5 | 用 + / − 分糖，糖要分完、每人不一样多：4 人 9 颗（不用 0 就做不到）、4 人 5 颗（最少要 6，做不到） |
| 最少几个人？ | 6–7 | 调人数，看「都不一样最少要几颗」的楼梯图和「我们有几颗」比一比：20 颗 → 7 人，60 颗 → 12 人 |
| 奥数真题 | 🏆 | 原题（标明出处；马来文、英文为原文，华语为翻译），用同一个工具解出 46 |
| 狄利克雷抽屉原理 | 📖 | 没有游戏的一页：狄利克雷画像（代码绘制的插画）、⌈N ÷ k⌉、Schubfachprinzip 名字的由来，以及 B3 的关键一步 |
| 想一想 | 1–3 | 三道额外题的关卡牌，配插画：三色袜子、1–10 里和为 11（用 + / − 填答案）、6 人握手（说理题）。「提示」「看答案」随时可按 |

关卡刻意精简：会来玩这类游戏的孩子有一定数学天分，每关只放一个新想法。

- 卡住两次后出现 💡 提示；没有倒计时，错了不扣分
- `node tests/pigeon-logic.test.js`：所有结论用暴力枚举验证——放不放得下、能不能都不一样、最少几人（0–60 颗糖逐个搜索）、1000 颗 → 46、三道额外题的答案（握手题枚举全部 2¹⁵ 种情况）

## 游戏 2：公平切蛋糕（过中心的一刀）

走向 **OMK 2016 Bongsu 组 B 部分第 1 题**：两个长方形一个套在另一个里面，只用铅笔和没有刻度的直尺，画一条直线把中间的阴影分成面积相等的两块。（答案：分别连对角线找出两个中心，经过两个中心画线。）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 随手切 | 1–2 | 拖一条直线切长方形蛋糕，实时看两边各占百分之几。第 2 关直线绕着图钉转——只有朝着中心的方向能平分 |
| 只用直尺 | 3–4 | 只能连接纸上已有的两个点（角、图钉、线与线/线与边的交点，新线会产生新点）。第 3 关要先连对角线找出中心；第 4 关一刀平分两块蛋糕 |
| 奥数真题 | 🏆 | 原题（标明出处；马来文、英文为原文，华语为翻译），图和原题相似 |
| 火腿三明治定理 | 📖 | 施坦豪斯和巴拿赫的画像与故事；定理只说这条线存在，B1 要用中心对称、对角线找中心、「大 − 小」把它画出来 |
| 想一想 | 1–3 | 平行四边形 + 图钉、中心重合的两个长方形 + 图钉、L 形（要先延长一条边把它拆成两个长方形）。可以自己画，也可以看提示、看答案（答案会把作图画出来） |

- `node tests/cut-logic.test.js`：面积裁切和「数格子」核对；经过中心的直线平分、偏一点就不平分；每个「只用直尺」关卡的标准作图每一步都只用到纸上已有的点、只有最后一刀成功；一开始任何两点连线都不能直接成功（一定要先画辅助线）；随机生成 200 组套着的长方形，经过两个中心的线都平分阴影

## 游戏 3：加一的秘密（数字和与同余）

走向 **OMK 2016 Bongsu 组 B 部分第 2 题**：数字和能被 5 整除的数叫「优秀数」，找两个连续的优秀数。（答案例子：49999 和 50000。）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 加 1 会怎样 | 1–3 | 转 7 个数字轮组成 N，画面同时显示 N、N + 1 的数字和和变化。找加 1 后数字和变小的数 → 刚好少 17 的数 → N 和 N + 1 的数字和相差 5 的倍数的数 |
| 奥数真题 | 🏆 | 原题（标明出处；马来文、英文为原文，华语为翻译），用同一组数字轮找出答案 |
| 高斯的同余 | 📖 | 高斯画像（代码绘制的插画）；末尾 B 个 9 让数字和少 9B − 1，9B − 1 ≡ 0 (mod 5) ⇒ B ≡ 4；官方答案的完整形式；弃九法 |
| 想一想 | 1–3 | 数字和都是 7 的倍数（69999）、都是 3 的倍数（做不到！）、都是 11 的倍数（2899999）。可以自己转，也可以看提示、看答案 |

- `node tests/digit-logic.test.js`：「加 1 后数字和变化 = 1 − 9 × 末尾 9 的个数」对 0…10⁶ 每个数暴力核对；在 7 个数字轮范围内暴力搜索，最小的一对是 49999；m = 2…13 时「连续两个数字和都是 m 的倍数」存在 ⇔ m 不是 3 的倍数

## 游戏 4：加号游戏（9 的秘密）

走向 **OMK 2018 Bongsu 组 B 部分第 3 题**：2018 个 1 排成一行，在中间插加号，使和等于 8102，最多能插几个加号？（答案 1991。）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 放加号 | 1–4 | 点两个 1 之间的空隙放加号，实时看到总和和加号数。6 个 1 凑 24 → 30 个 1 凑 138 且加号最多（用 111 比用十二个 11 多 10 个加号）→ 10 个 1 凑 50（做不到！）→ 100 个 1 凑 1315（1 太多，改用「几个 1111、111、11」计数） |
| 奥数真题 | 🏆 | 原题（标明出处；马来文、英文为原文，华语为翻译），用同样的计数方式 |
| 9 的秘密 | 📖 | 每一段比单独的 1 多出 9 的倍数（9、108、1107），所以「总和 − 1 的个数」必须是 9 的倍数；先用长段最省 1 |
| 想一想 | 1–3 | 40 个 1 凑 1147、20 个 1 凑 2018（是 9 的倍数却做不到）、30 个 1 凑 138 但加号最少 |

- `node tests/plus-logic.test.js`：N ≤ 16 把所有放法逐个试遍；每一关（包括 2018 个 1 凑 8102）再用和公式无关的动态规划核对

## 游戏 5：涂立方体（伯恩赛德引理）

走向 **OMK 2018 Muda 组 A 部分第 5 题**：给立方体的一些面涂上绿色（至少一面），转一转能变成一样的算同一种，一共几种？（答案 9。）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 涂一涂 | 1–3 | 拖动（或按箭头）转动 3D 立方体，点面涂色；按「收集」放进收集册，和已收集的转一转相同时会指出是第几个。觉得找齐了就按「全部找齐了！」。恰好 1 面（1 种）→ 2 面（2 种）→ 3 面（2 种） |
| 奥数真题 | 🏆 | 原题（标明出处；马来文、英文为原文，华语为翻译）：至少涂一面，收集全部 9 种 |
| 伯恩赛德引理 | 📖 | 伯恩赛德画像（插画）；按涂几面分类和「涂 4 面 = 留 2 面」的互补；24 种转法求平均的伯恩赛德引理 |
| 想一想 | 1–2 | 恰好 4 面（2 种）、绿白两色全涂（10 种） |

- 立方体用 CSS 3D 画；看的角度固定，箭头和拖动放手后都会对齐到摆正的朝向；面的明暗随朝向变化
- `node tests/cube-logic.test.js`：游戏的 24 种转法和真正的三维旋转矩阵逐种核对；1–6 面、9 种、10 种都用两种独立方法数过；伯恩赛德引理的平均值也核对过

## 游戏 6：小棒拼正方形（高斯求和）

走向 **OMK 2018 Muda 组 B 部分第 1 题**：长 1、2、…、n 的小棒各一根，可以首尾接起来但不能截断，全部用上拼成正方形。1 ≤ n ≤ 2018 里有几个 n 可以？（答案 504。）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 拼一拼 | 1–5 | 点小棒、再点一条边，把小棒放上去（放不下会提示）；正方形预览实时画出来。n = 8 → n = 7 → n = 5（总长 15 不能平分，做不到！）→ n = 15 → 在 1 到 24 里点出所有能拼的 n |
| 奥数真题 | 🏆 | 原题（标明出处；马来文、英文为原文，华语为翻译），用 ±1/±10/±100 填答案 |
| 高斯求和 | 📖 | 高斯画像；1 到 100 配对求和的故事；n(n+1)/2 要被 4 整除 ⇒ n 除以 8 余 0 或 7；官方的配对拼法 |
| 想一想 | 1–3 | 拼 n = 16、1 到 100 里有几个（24）、改成等边三角形时最小的 n（5） |

- `node tests/stick-logic.test.js`：n ≤ 10（正方形）、n ≤ 13（三角形）把小棒分给各边的所有方式逐个试；n ≤ 60 用搜索真的拼出来；官方配对拼法对 2018 以内每个 n 都核对过

## 游戏 7：字母转转乐（最小公倍数）

走向 **OMK 2017 Muda 组 A 部分第 6 题**：A B C … J 每天按同一个规则替换（A → G、B → I……），8 月几日第一次回到原来的顺序？（答案 12。）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 换一换 | 1–4 | 按「下一天」看黑板上的字母怎么变（下面留着前几天的记录），回到原样时按「回来了！」；之后先想好第几天再填答案。圈圈眼镜把同一个圈的字母涂成同一种颜色。一个 4 圈 → 2 和 3 → 2 和 5 → 4 和 6（是 12 不是 24） |
| 奥数真题 | 🏆 | 原题（标明出处；马来文、英文为原文，华语为翻译），日期从 7 月 31 日数起 |
| 最小公倍数 | 📖 | 原题的四个圈画成箭头图；为什么是最小公倍数而不是乘积；用质因数求最小公倍数 |
| 想一想 | 1–2 | 12 个字母（圈长 3、4、5 → 60）；10 个字母最多能等几天（2 + 3 + 5 → 30） |
| 文化课：天干地支 | 🏮 | 从 1984 甲子年开始按「下一年」（或「跳 10 年」）：天干 10 张、地支 12 张牌，标着 1、2、3……；第 60 年（2044）才又是甲子年，不是 120 年——单数只配单数、双数只配双数，120 种配法只出现一半 |

- `node tests/letter-logic.test.js`：每关和 2000 个随机规则，都用「圈长的最小公倍数」和一天天模拟核对；10 个字母的所有圈长拆法逐个试过；天干地支 60 年一轮、只出现 60 种配法、1984 甲子 / 2024 甲辰 / 2026 丙午

## 部署到 GitHub Pages

推到 GitHub 仓库，Settings → Pages → Source 选 `main` 分支根目录。没有构建步骤。
每次改了 CSS / JS，把 HTML 里的 `?v=N` 加 1，让浏览器拿到新文件。

## 加一个游戏

- `xxx.html` + `js/xxx-logic.js`（纯规则，UMD，Node 能直接 require）+ `js/xxx-game.js`（界面）+ 图画文件（SVG）
- `tests/xxx-logic.test.js`：用程序验证数学正确性，`node tests/xxx-logic.test.js` 运行
- 在 `index.html` 加一张卡片，在 `strings.js` 加文字
