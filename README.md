# 思维小游戏 · Think & Play

给 8–12 岁孩子的免费、开源网页小游戏：先玩、先试错、自己发现规律，通关后再用一句话点破背后的数学。

> 项目重新开始：之前的三个游戏（取石子、说谎者与诚实者、一笔画与涂地图）已移除，代码仍保存在 git 历史里（提交 `b5e7328` 及之前）。

- 纯静态：HTML + CSS + JavaScript，无构建步骤、无后端、无账号
- 不收集任何信息、没有追踪脚本；进度只存在本机浏览器（localStorage，读写都包 try/catch）
- 所有图形用 SVG / Canvas 代码绘制，音效用 WebAudio 现场合成（可静音）
- 三语：华语、英语、马来文（Bahasa Melayu）
- 大字、高对比、触屏友好；失败不惩罚，没有倒计时
- 用户开了「减少动态效果」时不做动画

## 怎么玩

直接双击 `index.html`（脚本用普通 `<script>` 加载，`file://` 下也能运行），或者：

```bash
python3 -m http.server 8765
```

## 游戏 1：鸽子与糖果（抽屉原理）

一步步走向 **2016 年马来西亚全国数学奥林匹克（OMK 2016）Bongsu 组 B 部分第 3 题**：
1000 颗糖分给 n 个小朋友（可以分到 0 颗），最小的 n 是多少，才一定有两人分到一样多？（答案 46）

| 章 | 关卡 | 孩子在做什么 |
|---|---|---|
| 鸽子回家 | 1–6 | 点窝放鸽子，每窝有上限。有的关放得下，有的放不下——放不下就按「做不到！」。第 2 关通关后点出「抽屉原理」这个名字 |
| 都不一样多 | 7–11 | 用 + / − 给小朋友分糖，糖要分完、每人不一样多（可以 0 颗）。发现最省的分法是 0、1、2…… |
| 最少几个人？ | 12–14 | 调人数，看「都不一样最少要几颗」的楼梯图和「我们有几颗」比一比，找出最少几人一定撞 |
| 奥数真题 | 15 | 原题（标明出处；马来文、英文为原文，华语为翻译），用同一个工具解出 46 |

- 通关真题后显示解答：每一步都对应前面哪一章；再给大人看的一段（狄利克雷、⌈N/k⌉）
- 「想一想」：三道额外的抽屉原理题（三色袜子、1–10 里和为 11、6 人握手），提示和答案都可以点开
- 卡住两次后出现 💡 提示；没有倒计时，错了不扣分
- 皮肤：鸽子 / 糖果罐（只换样子和名词，规则不变）
- `node tests/pigeon-logic.test.js`：所有结论用暴力枚举验证——放不放得下、能不能都不一样、最少几人（0–60 颗糖逐个搜索）、1000 颗 → 46、三道额外题的答案（握手题枚举全部 2¹⁵ 种情况）

## 部署到 GitHub Pages

推到 GitHub 仓库，Settings → Pages → Source 选 `main` 分支根目录。没有构建步骤。
每次改了 CSS / JS，把 HTML 里的 `?v=N` 加 1，让浏览器拿到新文件。

## 文件

```
index.html        首页（游戏卡片）
css/style.css     共用样式：顶栏、按钮、卡片、弹窗、选关、规则列表
js/core.js        共用工具：本地存储、伪随机数、多语言、音效、图标、顶栏
js/strings.js     所有界面文字（zh / en / ms）
js/fx.js          通关时撒星星（canvas）
pigeon.html               游戏 1：鸽子与糖果
js/pigeon-logic.js        规则和关卡（纯函数，Node 可直接 require）
js/pigeon-skins.js        鸽子、窝、糖果、罐子、小朋友的 SVG
js/pigeon-game.js         界面
tests/pigeon-logic.test.js
```

## 加一个游戏

- `xxx.html` + `js/xxx-logic.js`（纯规则，UMD，Node 能直接 require）+ `js/xxx-game.js`（界面）+ 皮肤文件
- `tests/xxx-logic.test.js`：用程序验证数学正确性，`node tests/xxx-logic.test.js` 运行
- 在 `index.html` 加一张卡片，在 `strings.js` 加文字
