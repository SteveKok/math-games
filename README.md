# 思维小游戏 · Think & Play

给 8–12 岁孩子的免费、开源网页小游戏：先玩、先试错、自己发现规律，通关后再用一句话点破背后的数学。

- 纯静态：HTML + CSS + JavaScript，无构建步骤、无后端、无账号
- 不收集任何信息、没有追踪脚本；进度只存在本机浏览器（localStorage）
- 所有图形用 SVG / Canvas 代码绘制，音效用 WebAudio 现场合成（可静音）
- 中文 / 英文，已预留马来文

## 怎么玩

直接双击 `index.html` 就能玩（脚本用普通 `<script>` 加载，`file://` 下也能运行）。

或者起一个本地服务器：

```bash
python3 -m http.server 8765
```

## 部署到 GitHub Pages

把整个目录推到 GitHub 仓库，Settings → Pages → Source 选 `main` 分支根目录即可。没有任何构建步骤。

## 游戏 1：取石子（Nim）

几堆物品，孩子和电脑轮流拿，每次只能从**一堆**里拿任意个（至少 1 个），拿到最后一个的人赢。

- 11 关：2 堆 → 3 堆 → 4 堆；电脑从随机下逐步变成最优策略
- 孩子总是先手，每一关的起始局面都**由测试程序验证过一定有必胜走法**
- 从第 5 关起有「分组眼镜」：把每堆按 8/4/2/1 分组上色，帮孩子自己看出"成对"的规律（不出现"二进制""异或"等术语）
- 连输两次后出现 💡 提示按钮，会把一步必胜走法高亮出来
- 皮肤：糖果、石头、星星。皮肤只负责画图，规则逻辑只写一次

### 背后的数学（通关后在游戏里展示）

两堆时：两堆一样多、又轮到对手，对手就输定了——他拿多少，你就在另一堆拿多少。

多堆时：把每堆拆成 8、4、2、1 的小份。如果每种小份都出现偶数次（成对），轮到的人必输；否则总有一步能让它们重新成对。这就是二进制下各堆数量的**异或（XOR）**：异或为 0 的局面是必败局面（C. L. Bouton, 1901）。

## 游戏 2：说谎者与诚实者

每个角色要么**诚实**（说的话一定为真），要么**说谎**（说的话一定为假）。孩子给每个人选「诚实」或「说谎」，按「检查」：说得通的人打 ✓，说不通的打 ✗，可以无限次改。

- 10 关：2 人 → 3 人 → 4 人；每关引入新句式（「我和 X 是同一种人」「都是」「至少一个」「正好 N 个」……）
- **题目由程序随机生成**：枚举全部 2ⁿ 种身份组合，只保留恰好一种说得通、且诚实和说谎的人都有的题目，所以每题答案唯一
- 「换一题」随时出一道同难度的新题；连错两次后出现 💡，会帮孩子确定一个人
- 皮肤：小怪兽、机器人。选「诚实」头顶出现光环，选「说谎」长出小角
- 首次进入自动弹出规则说明

## 测试

数学正确性由程序保证，不靠猜：

```bash
node tests/nim-logic.test.js
```

```bash
node tests/liar-logic.test.js
```

说谎者游戏的测试用一个**独立写的求解器**（集合表示、递归枚举）交叉验证：每关生成 300 道题都唯一解、句式合法、只有正确答案能让所有人都「说得通」。

取石子的测试用**暴力 minimax 搜索**（完全不依赖异或理论）独立验证：

1. 1–4 堆、每堆 0–8 的所有局面：「异或 ≠ 0」⇔「先手必胜」
2. `winningMoves` 给出的走法与暴力搜索找到的必胜走法完全一致
3. 每一关孩子先手都有必胜走法
4. 电脑在任意难度下只走合法步，且最优电脑在必胜局面下永不输

## 目录结构

```

js/liar-logic.js    题目表示、求解、生成、关卡（纯逻辑）
js/liar-chars.js    角色皮肤（小怪兽、机器人）
js/liar-game.js     说谎者游戏的界面与交互
tests/              Node 测试
```

## 扩展

- **加皮肤**：在 `js/skins.js` 里照 `candy` 的样子加一个 `{ id, nameKey, draw(seed, uid) }`，并放进 `MG.SKINS`；在 `strings.js` 加上名字。同一个 seed 必须画出同一个形状。
- **加语言**：在 `js/strings.js` 里补全对应语言的对象，然后把 `js/core.js` 里 `MG.LANGS` 中该语言的 `enabled` 改为 `true`。缺的文字会自动回落到英文。
- **加关卡**：改 `js/nim-logic.js` / `js/liar-logic.js` 里的 `LEVELS`，再跑一次测试。
- **发布新版本**：改了 CSS/JS 后，把各 HTML 里 `?v=N` 的数字加一，浏览器才会马上用新文件（GitHub Pages 会缓存约 10 分钟）。
